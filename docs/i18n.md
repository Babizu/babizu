# 多語言介面

網站介面的每一段文字都來自語系檔；站台自己的內容（名稱、方言名稱、「關於」頁…）則在站台設定裡依語系提供。

## 內建語系

| 代碼 | 名稱 | 檔案 |
|---|---|---|
| `zh-TW` | 中文 | `locales/zh-TW.json` |
| `en` | English | `locales/en.json` |

兩個檔案的鍵完全相同（單元測試會檢查：程式用到的每個鍵每個語系都要有、參數佔位符 `{name}` 一致）。

## 站台啟用哪些語系

```js
// babizu.config.js
export default defineSite({
  locales: ['zh-TW', 'en', 'pzh'], // 第一個是預設語系（或另外指定 defaultLocale）
  localeNames: { pzh: '族語' }, // 語系選單上的名稱；內建語系已有名稱
  // …
})
```

- 只有一個語系時不顯示語系選單。
- 第一次來訪時依瀏覽器偏好語言選擇（完全相符優先，其次主要語言相同，例如 `en-US` → `en`），都不符合就用預設語系。
- 讀者的選擇存在瀏覽器（`<站台 id>:locale`），並設定 `<html lang>`。

## 覆寫字串、新增語系

在站台目錄的 `locales/<語系>.json` 放要覆寫或新增的字串，格式與內建檔案相同（巢狀物件）。
只需要寫想改的鍵：

```json
{
  "filter": {
    "fuzzinessHint": "「標準」會找出方言對應（例如 r 脫落、詞尾 l→n）與少量拼寫差異；…"
  }
}
```

**新增語系**（例如族語介面）時，可以先只翻一部分：缺少的字串會回退到預設語系。
`babizu locales` 列出每個語系缺少哪些字串與預設語系的原文，方便分批翻譯：

```
$ npx babizu locales
pzh（族語）缺 268 個：
  about.audio.count  ← {count} 段錄音
  …
```

## 依語系提供的站台內容

站台設定中標為 Localized 的欄位（`title`、`description`、`varieties[].label`、`examples[].note`、`footer`、`about`…）
可以是字串或 `{ 語系: 文字 }`，缺的語系用預設語系的內容。見 [site-config.md](site-config.md)。

語言設定檔中規則分類的名稱也可以依語系提供（`rules[].label`），演算法實驗室與搜尋結果的說明會使用。

## 在前端程式中使用

```vue
<script setup>
import { useI18n } from '@/i18n.js'
const { t, tr, formatCount } = useI18n()
</script>

<template>
  <p>{{ t('search.noResultsFor', { query }) }}</p>  <!-- 介面字串，{query} 代入參數 -->
  <h1>{{ tr(site.title) }}</h1>                      <!-- 站台設定中依語系提供的文字 -->
  <span>{{ formatCount(12345) }}</span>              <!-- 依語系加千分位 -->
</template>
```

- `t(key, params)`：找不到時依序回退到預設語系、鍵名本身（畫面上出現鍵名就表示漏了字串）。
- 代碼的顯示名稱（單位、角色、來源類型、校對狀態…）用 `app/src/lib/labels.js` 的輔助函式，不要自己拼鍵名。
- 新增介面字串時，`zh-TW.json` 與 `en.json` 都要加，否則單元測試會失敗。

不使用 vue-i18n：需要的只是「查字串＋代入參數＋回退」，自己寫不到一百行，也少一個依賴。
